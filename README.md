# 내 옷장 — v3.8

개인이 iPhone Safari와 홈 화면 웹앱에서 사용하는 무료 옷장입니다. GitHub Pages의 정적 `index.html`로 실행하며 서버·유료 API·회원 계정이 없습니다.

개발 전 [PROJECT.md](PROJECT.md)를 먼저 읽으세요. 기존 IndexedDB `wardrobeDB`(version 1)의 `clothes`, `outfits`와 JSON 백업 호환성을 유지합니다.

## 사용

- 사진을 여러 장 선택하고 카테고리·세부종류·색상·계절·격식도·메모를 확인한 뒤 저장합니다.
- AI는 MobileNet V2 alpha 0.5로 기기에서 실행합니다. 라이브러리·모델 다운로드에는 인터넷이 필요하며 영구 캐시와 완전한 오프라인 동작은 보장하지 않습니다.
- 대분류·세부종류·색상은 각각 근거가 부족하면 확인을 요청합니다. 세부종류는 비워둘 수 있습니다. 사용자가 수정한 값은 재분석이 덮어쓰지 않습니다.
- 현재 패딩을 별도 학습한 모델은 없습니다. 일반 외투를 코트로 강제 입력하지 않고 세부종류 확인을 요청합니다.
- ‘테스트 결과 내려받기’는 사진과 메모를 제외한 분석 근거 및 선택값을 JSON으로 저장합니다. 정답으로 수정한 뒤 내려받아 비교에 활용하세요. 이 기록은 페이지를 닫으면 사라집니다.
- 옷장 백업에는 사진이 포함됩니다. 테스트 JSON과 구별하세요. 복원은 현재 옷장과 저장 코디를 교체합니다.
- 앱의 ‘최신 버전 확인’ 또는 ‘강제 새로고침’으로 v3.8을 확인할 수 있습니다.

## v3.8 변경

실사진 6장의 v3.7 진단에서 모든 모델 출력이 동일한 이상을 확인했습니다. 정확한 iPhone 실패 단계는 아직 미확정입니다.

- 같은 MobileNet을 CPU backend에서 실행하고, canvas에서 읽은 RGB 숫자 텐서를 전달합니다. 처리시간은 기기에서 확인이 필요합니다.
- 사진 입력 hash·통계·backend·처리시간을 진단에 기록합니다. 사진/메모/파일명은 제외합니다.
- 서로 다른 입력의 동일 출력은 분석 이상으로 표시하고 자동 입력을 보류합니다.
- 검정 가죽의 회색 반사와 검정·회색 배색은 색상 확인을 요청합니다.
- DB/백업 형식 및 모델은 유지합니다. 실제 iPhone 분류 개선 여부는 새 진단으로 확인해야 합니다.

## v3.7 변경

- 대분류 점수 합산과 세부종류 보류 기준 분리.
- 저채도 카키/회색 경계 확인, 배경 중앙값 0 오류 및 흰 전경 처리 개선.
- 수동 입력 보호, 등록 대기 사진 제외, 중복 저장 방지.
- 이미지 사전검증 및 두 저장소의 원자적 백업 복원.
- 저장 transaction 오류 처리, HTML 텍스트 이스케이프, Object URL 수명 관리.
- 날씨·계절을 실제 반영하는 코디 점수.

실사진으로 임계값을 보정하기 전이므로 정확도 향상을 수치로 보장하지 않습니다. 저장 코디 생성·목록 화면과 아우터 포함 추천은 후속 검토 항목입니다.

## 회귀 검사

Node.js와 Playwright Chromium을 사용합니다. 앱 실행에 테스트 도구 설치는 필요하지 않습니다. 아래 설치는 개발 환경에서만 수행합니다.

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/regression.cjs
```

별도 Chromium 실행 파일이 준비되어 있으면 `WARDROBE_TEST_CHROMIUM` 환경변수로 지정할 수 있습니다.

검사는 임시 로컬 서버와 새 브라우저 컨텍스트의 IndexedDB를 사용합니다. 사용자 앱 주소나 실제 옷장 데이터에 접근하지 않으며 외부 네트워크 요청을 차단합니다. 합성 이미지·통제된 모델 출력, 구버전 형식의 합성 백업을 사용합니다.

30개 검사 통과: 분류·색상·날씨, 수동 입력 보호, 백업 왕복·오류 롤백, 일괄 등록·중복 방지, 모델 로딩 실패, 진단 데이터와 텍스트 이스케이프 등. iPhone Safari/홈 화면 모드와 실제 옷 사진 정확도는 별도 확인이 필요합니다.


### 로컬 실사진 입력 검사

```sh
npm install --no-save --package-lock=false playwright @tensorflow/tfjs@4.22.0
npx playwright install chromium
WARDROBE_PHOTO_DIR=/path/to/photos node tests/photo-input.cjs
```

필요하면 WARDROBE_TEST_TFJS로 로컬 tf.min.js 파일 경로, WARDROBE_TEST_CHROMIUM으로 브라우저 경로를 지정합니다. 사진은 로컬에서만 읽고 외부 요청은 차단합니다. 실제 TensorFlow.js의 RGB 텐서 전달을 검사하며 사전학습 모델의 인식 정확도는 검사하지 않습니다. 제공받은 6장에 대해 입력이 서로 다르고 텐서 픽셀이 일치함을 확인했습니다. 사진 자체는 저장소에 포함하지 않습니다.
