쇼핑몰 상품 가져오기

단축어를 한 번 만들어 두면 상품 페이지 → 공유 → 단축어 → 옷장 앱에서 붙여넣기로 등록합니다. 사진·구매 색상·사이즈는 저장 전에 확인합니다.

설치용 단축어 파일이 아니라 직접 만드는 안내입니다. iOS 언어·버전에 따라 동작 이름이 조금 다를 수 있습니다. 코드는 상품 정보(이름·브랜드·가격·사진 주소 등)만 읽으며 계정 정보·쿠키·장바구니를 읽지 않습니다.

1. Safari용 단축어 (짧은 버전, 권장)

사진은 옷장 앱이 직접 받습니다. 그래서 단축어에서 사진을 받고 바꾸는 단계가 없어 빠릅니다. 무신사·29CM·W컨셉·SSF·지그재그·코오롱과 Cafe24 쇼핑몰(스테디에브리웨어·포터리·로커드 등)에서 확인했습니다.

  1. iPhone 단축어 앱에서 새 단축어를 만들고 이름을 옷장 상품 가져오기로 정합니다.
  2. 단축어 세부사항에서 공유 시트에서 보기를 켜고 입력 유형은 Safari 웹 페이지로 정합니다.
  3. 웹 페이지에서 JavaScript 실행 동작을 추가합니다. 입력은 단축어 입력으로 두고, 기본 코드를 모두 지운 뒤 아래 코드로 교체합니다.

  1. 사전 값 가져오기: 키 metadata, 입력은 JavaScript 결과.
  2. 클립보드에 복사.

JavaScript 실행 허용을 물으면 허용합니다. 상품 상세페이지에서만 실행하세요.

이미 사진까지 가져오는 긴 버전을 만들었다면: JavaScript 코드를 위 새 코드로 바꾸고, 두 번째 사전 값 가져오기(imageUrl)부터 조건문 끝까지와 변수 설정을 지웁니다. 사전 값 가져오기(metadata) → 클립보드에 복사만 남기면 됩니다. 지운 뒤 클립보드에 복사의 입력 칸을 눌러 사전 값으로 다시 지정합니다.

사진 서버가 막힌 쇼핑몰(유니클로·스파오·에이블리 등)용 긴 버전

이 쇼핑몰들은 앱이 사진을 직접 받지 못합니다. 짧은 버전으로 가져와 옷장에서 사진을 고르거나, 아래처럼 단축어가 사진까지 넘기게 합니다.

  1. 사전 값 가져오기: 키 metadata, 입력은 JavaScript 결과. 다음에 변수 설정으로 이름을 상품정보로 정합니다.
  2. 사전 값 가져오기: 키 imageUrl, 입력은 다시 JavaScript 결과.
  3. 조건문: 사진 주소에 값이 있는 경우. 안에 URL의 콘텐츠 가져오기 → 이미지 크기 조절(너비 1200) → 이미지 변환(JPEG) → Base64 인코딩(줄바꿈 없음) → 텍스트:
{
  "metadata": [상품정보 변수],
  "imageBase64": "[Base64 인코딩 결과 변수]"
}

대괄호 부분은 변수 칩으로 넣습니다. metadata 뒤에는 따옴표를 붙이지 않고, imageBase64 값의 양쪽 따옴표는 유지합니다. 그렇지 않은 경우에는 텍스트에 상품정보 변수만 넣고, 조건문 뒤 클립보드에 복사(입력: 조건문 결과).

2. 쇼핑몰 앱용 단축어 (무신사·29CM 앱)

쇼핑몰 앱의 공유 버튼은 페이지가 아니라 주소만 넘겨 1번 단축어가 돌지 않습니다. 이 단축어는 공유 주소에서 상품 주소를 찾아 상품 페이지를 받아 옵니다.

PC에서 무신사 공유 주소와 29CM 공유 주소 일부, 두 쇼핑몰 상품 페이지로 확인했고, iPhone 단축어에서 끝까지 돌려 보지는 않았습니다. 29CM 공유 주소 중에는 상품 주소 없이 App Store로만 연결되는 것이 있습니다. 안 되면 아래 '안 될 때'를 보세요.

  1. 새 단축어 이름을 옷장 상품 가져오기(앱)로 정하고, 공유 시트에서 보기를 켠 뒤 입력 유형은 URL과 텍스트로 정합니다.
  2. 입력에서 URL 가져오기.
  3. URL의 콘텐츠 가져오기(입력: 앞의 URL).
  4. 이름 설정: 이름을 page.txt로 정합니다(단축어가 페이지를 글자 그대로 다루게 하는 단계).
  5. 텍스트 일치: 아래 정규 표현식, 입력은 앞 단계 결과.
https://www\.(musinsa\.com|29cm\.co\.kr)/products/[0-9]+
  1. 조건문: 일치 항목에 값이 있는 경우. 안에 다음을 넣습니다.
    1. 목록에서 항목 가져오기: 첫 번째 항목.
    2. URL의 콘텐츠 가져오기(입력: 첫 번째 항목).
    3. 이름 설정: page.txt(원문 그대로 인코딩되게).
    4. Base64 인코딩: 줄바꿈 없음.
    5. 클립보드에 복사.
    6. 알림 표시: 복사했습니다. 옷장에서 붙여넣기를 누르세요
  2. 그렇지 않은 경우: 알림 표시 상품 주소를 찾지 못했습니다.

공유 주소에는 공유한 사람을 알아보는 값이 들어 있지만, 옷장에는 쇼핑몰이 알려 주는 상품 주소에서 추적값을 뺀 주소만 저장합니다. 옷장 앱이 사진·페이지를 받을 때는 쿠키와 보던 페이지 정보를 보내지 않지만, 요청한 앱 주소(github.io)는 쇼핑몰에 전달됩니다.

안 될 때: 무신사는 앱에서 공유 → 링크 복사 → Safari 주소창에 붙여 넣어 상품 페이지를 연 뒤 1번 단축어를 실행합니다. 29CM 링크가 App Store로 가면 Safari에서 29cm.co.kr을 열어 상품을 검색한 뒤 1번 단축어를 실행합니다. 어느 단계에서 멈췄는지(알림 문구, 옷장의 안내 문구) 알려 주시면 고치겠습니다.

3. 실제 등록

  1. 상품 페이지(Safari) 또는 쇼핑몰 앱에서 공유 → 만든 단축어를 실행합니다.
  2. 옷장 앱을 엽니다. 홈 화면 앱을 쓰면 그 앱을 여세요.
  3. 쇼핑몰 상품 붙여넣기(옷장 첫 화면) 또는 옷 등록 → 쇼핑몰 상품 가져오기 → 붙여넣기를 누르고, iPhone이 묻는 붙여넣기를 누릅니다.
  4. 사진·상품 정보·구매 옵션 확인 → 등록 목록에 추가 → 분류·색 확인 → 모두 저장.

기존 옷장은 유지되고 새 옷만 추가됩니다. 사진이 마음에 들지 않으면 미리보기의 사진 선택·교체로 바꿉니다.

세탁 라벨도 보관하기

옷장 카드의 수정 → 세탁 라벨·관리에서 라벨 사진, 제조사 안내, 개인 메모, 마지막 세탁일을 저장할 수 있습니다. 사진을 누르면 크게 볼 수 있습니다.

iPhone 사진 앱에서 라벨 문장을 길게 눌러 복사하거나 라이브 텍스트 버튼을 사용한 뒤 세탁 안내 칸에 붙여 넣으세요. 앱이 세탁 기호를 자동 판독하거나 소재만으로 세탁법을 확정하지는 않습니다.

공식 안내: Apple Safari JavaScript 단축어 · Apple 라이브 텍스트
