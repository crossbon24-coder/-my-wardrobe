쇼핑몰 상품 가져오기

한 번 설정하면 Safari 상품 페이지 → 공유 → 단축어 → 옷장에 붙여 넣기로 등록할 수 있습니다. 사진·구매 색상·사이즈는 저장 전에 확인합니다.

설치용 단축어 파일이 아니라 직접 만드는 안내입니다. 아래 코드는 브라우저 검사로 확인했으며 iPhone 단축어 전체 실행과 쇼핑몰별 지원 여부는 실제 링크로 확인이 필요합니다. iOS 언어·버전에 따라 동작 이름이 조금 다를 수 있습니다.

1. 단축어 만들기

  1. iPhone 단축어 앱에서 새 단축어를 만들고 이름을 옷장 상품 가져오기로 정합니다.
  2. 단축어 세부사항에서 공유 시트에서 보기를 켜고 입력 유형은 Safari 웹 페이지로 정합니다.
  3. 웹 페이지에서 JavaScript 실행 동작을 추가합니다. 입력은 단축어 입력으로 두고, 기본 코드를 모두 지운 뒤 아래 코드로 교체합니다.

JavaScript 실행 허용을 요청하면 Apple의 안내에 따라 단축어 설정에서 허용합니다. 상품 상세페이지에서만 실행하세요. 코드는 상품 메타데이터만 읽으며 계정 정보·쿠키·장바구니를 수집하지 않습니다.

2. 사진도 함께 가져오기

첫 번째 JavaScript 동작은 metadata(상품 정보)와 imageUrl(대표 사진 주소)을 반환합니다. 이후 동작을 다음 순서로 추가합니다.

  1. 사전 값 가져오기: 키 metadata, 입력은 첫 번째 JavaScript 결과.
  2. 변수 설정: 이름을 상품정보로 정합니다.
  3. 사전 값 가져오기: 키 imageUrl, 입력은 다시 첫 번째 JavaScript 결과를 선택합니다. 바로 앞 상품정보 텍스트를 입력으로 쓰지 않습니다.
  4. 조건문: 사진 주소에 값이 있는 경우.
  5. 조건문 안에 URL의 콘텐츠 가져오기를 추가합니다. 주소는 imageUrl의 값이고 방식은 GET입니다.
  6. 이미지 크기 조절: 너비 1200, 높이 자동.
  7. 이미지 변환: JPEG로 변환합니다.
  8. Base64 인코딩: 변환한 이미지를 인코딩합니다. 줄바꿈은 없음으로 설정합니다.
  9. 텍스트 동작에 아래 내용을 넣습니다. 대괄호 부분은 직접 타이핑하는 글자가 아니라 해당 변수 칩으로 교체합니다.
{
  "metadata": [상품정보 변수],
  "imageBase64": "[Base64 인코딩 결과 변수]"
}

metadata 뒤 상품정보 변수에는 따옴표를 붙이지 않습니다. imageBase64 값의 양쪽 따옴표는 유지합니다.

  1. 조건문의 그렇지 않은 경우에는 텍스트 동작에 상품정보 변수만 넣습니다.
  2. 조건문이 끝난 뒤 클립보드에 복사를 추가하고 입력을 조건문 결과로 지정합니다.

사진 서버가 다운로드를 거부하면 단축어가 중단될 수 있습니다. 그때는 아래 정보 전용 방식으로 가져온 뒤 옷장에서 사진을 선택하세요. 대표 사진이 구매 옵션과 다른 경우도 있으므로 반드시 미리보기를 확인합니다.

간단한 대안: 정보만 가져오기

JavaScript 실행 뒤 사전 값 가져오기(metadata) → 클립보드에 복사만 연결해도 됩니다. 옷장 앱이 사진 주소로 다운로드를 시도하고, 허용되지 않으면 사진 선택을 안내합니다.

3. 실제 등록

  1. 구매한 상품을 Safari에서 열고 공유 메뉴에서 만든 단축어를 실행합니다. 쇼핑몰 앱의 링크 공유만으로는 Safari 웹 페이지 입력이 전달되지 않을 수 있습니다.
  2. 평소 사용하는 옷장 앱을 직접 엽니다. 홈 화면 앱을 쓰면 그 앱을 여세요.
  3. 옷 등록 → 쇼핑몰 상품 가져오기에 붙여 넣고 상품 미리보기를 누릅니다.
  4. 사진·상품 정보·구매 옵션 확인 → 등록 목록에 추가 → 카테고리·색상 확인 → 모두 저장.

기존 옷장은 유지되고 새 옷만 추가됩니다. 백업 복원 기능을 사용하지 않습니다.

세탁 라벨도 보관하기

옷장 카드의 수정 → 세탁 라벨·관리에서 라벨 사진, 제조사 안내, 개인 메모, 마지막 세탁일을 저장할 수 있습니다. 사진을 누르면 크게 볼 수 있습니다.

iPhone 사진 앱에서 라벨 문장을 길게 눌러 복사하거나 라이브 텍스트 버튼을 사용한 뒤 세탁 안내 칸에 붙여 넣으세요. 앱이 세탁 기호를 자동 판독하거나 소재만으로 세탁법을 확정하지는 않습니다.
